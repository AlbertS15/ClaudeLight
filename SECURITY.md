# Security policy

Lumi stores API keys (in the macOS Keychain, or encrypted with Windows DPAPI) and runs model command-line tools, so security reports matter.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately instead: [Security → Report a vulnerability](https://github.com/AlbertS15/Lumi/security/advisories/new). You can write in English or Russian.

Include what the problem is, how to reproduce it and which version and system you used. You'll get a reply as soon as possible, and the fix will ship in a new release with credit to you, unless you prefer not to be named.

## Supported versions

Only the [latest release](https://github.com/AlbertS15/Lumi/releases/latest) gets fixes. Lumi checks for new versions once a day and offers the update in its menu.
