Как подключить модель в Lumi: Ollama и OpenRouter Что выбрать • Ollama — модель работает прямо на компьютере: бесплатно, без лимитов, без аккаунта, работает в любой стране. Нужно от 8 ГБ памяти, лучше 16. • OpenRouter — облачные модели, есть бесплатные с дневным лимитом. Подходит для любого компьютера, но из России не работает (ошибка 403). Ollama на Mac 1. Установите Ollama с ollama.com или командой brew install ollama и запустите её. 2. Скачайте модель в Терминале, например ollama pull qwen3.5:9b 3. В Lumi: плашка модели → «Подключить модель…» → сервис Ollama → модель qwen3.5:9b, ключ пустой. Какую модель взять: • 8 ГБ — qwen3.5:4b • 16 ГБ — qwen3.5:9b (лучший выбор) или gemma4:12b • 24–32 ГБ — gpt-oss:20b (открытая модель OpenAI) • 32 ГБ+ — gemma4:26b Ollama на Windows То же самое: установщик с ollama.com/download, модель скачивается в PowerShell той же командой, строка открывается по Alt+Ё. OpenRouter 1. Зарегистрируйтесь на openrouter.ai → Keys → Create Key. Для бесплатных моделей поставьте лимит расходов 0 $. 2. В Lumi: «Подключить модель…» → сервис OpenRouter → вставьте ключ и ID модели. Бесплатные модели: • google/gemma-4-31b-it:free — хорошо знает русский • nvidia/nemotron-3-super-120b-a12b:free — крупная и сильная • nvidia/nemotron-3.5-lightning:free — очень быстрая Если не работает • «Запущен ли сервер модели?» — запустите приложение Ollama • 404 у Ollama — проверьте имя модели командой ollama list • 403 у OpenRouter — сервис недоступен в вашей стране, берите Ollama • 429 или пустой ответ — бесплатная модель перегружена, подождите или возьмите другую :free После исправления нажмите ↩ в пустой строке — вопрос повторится.
