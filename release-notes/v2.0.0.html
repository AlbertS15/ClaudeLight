Lumi 2.0: теперь и на Linux 🐧👻 Вы просили, и вот: Lumi работает на трёх системах — Mac, Windows и Linux. Lumi для Linux • Один файл AppImage: скачали, разрешили запуск, открыли. Рассчитана на Ubuntu, Fedora, Debian и другие дистрибутивы для обычных компьютеров (x86-64). • Всё, что умеет Lumi: ответы Claude, ChatGPT и Gemini по вашей подписке, OpenRouter и другие сервисы, запуск приложений и поиск файлов, пять языков интерфейса. • ИИ без интернета одной кнопкой: Lumi сама поставит Ollama в вашу домашнюю папку (без пароля администратора, с проверкой контрольной суммы) и настроит свою модель. • Горячая клавиша по умолчанию Ctrl+Пробел: привычный Alt+Ё в GNOME и KDE уже занят системой. В GNOME Lumi назначает клавишу сама. Это первая версия для Linux. Если что-то работает не так, напишите нам: поправим быстро. Своя горячая клавиша — на всех системах • В окне Lumi нажмите «Изменить» под клавишами и задайте любое сочетание, например Ctrl+Пробел или F5. • Если сочетание занято другой программой, Lumi скажет об этом и оставит прежнее. • «Сбросить» возвращает клавишу по умолчанию. Как обновиться: на Mac и Windows Lumi сама покажет «Доступна Lumi 2.0.0 — скачать». На Linux скачайте Lumi-x86_64.AppImage со страницы выпуска.
