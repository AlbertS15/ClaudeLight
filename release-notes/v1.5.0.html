Lumi 1.5.0: ИИ без интернета, теперь в одну кнопку 👻⚡ Раньше для своих моделей Lumi нужно было сначала отдельно скачать и установить Ollama. Теперь не нужно. • Всё одной кнопкой. «Подключить модель…» → Ollama → «Установить Lumi». Если Ollama на компьютере нет, Lumi сама скачает её, установит, запустит, а потом поставит модель. • Безопасно. Lumi ставит Ollama только с официального сайта и только если файл подписан разработчиком Ollama. Подменённый файл Lumi не установит. • Права администратора не нужны. Размер загрузки: Ollama занимает 0.2 ГБ на Mac и 1.6 ГБ на Windows (в ней библиотеки для видеокарт), плюс сама модель от 4.6 ГБ. Всё скачивается один раз, дальше Lumi работает без интернета. Как обновиться: Lumi сама покажет «Доступна Lumi 1.5.0 — скачать» в меню. Или скачайте новую версию и установите поверх старой, настройки сохранятся.
